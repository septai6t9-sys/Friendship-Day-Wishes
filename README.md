
# Friendship Day Interactive Web Experience

An ultra-premium, cinematic, interactive web application built for Friendship Day by **ISHAAN 💙**.

## 🚀 Setup Instructions

1. Create a root directory named `friendship-day-experience/`.
2. Save the files in your folder as follows:
   - Save the HTML code into `index.html`.
   - Save the CSS code into `style.css`.
   - Save the JavaScript code into `script.js`.
3. Open `index.html` in any modern web browser (Google Chrome, Safari, Firefox, Edge).

## 🛠 Features

- **Built-In Sound FX**: Synthesized audio powered by the Web Audio API (no external sound files required).
- **Custom Particles Canvas**: Starfields, particle effects, and floating light trails.
- **AI Scanner**: Holds biometrics and generates friendship stats.
- **Roast Machine & Spin Wheel**: Interactive mini-apps for roasts and treats.
- **Arcade (4 Mini Games)**: Catch Hearts, Pop Balloons, Memory Match, and Reflex Challenge.
- **Secret Vault**: Unlocks secret messages using the passcode `FRIEND`.
- **Downloadable Passport & Certificate**: Generated dynamically using HTML5 Canvas.
- **Grand Finale**: Cinematic outro with dynamic confetti fireworks.
