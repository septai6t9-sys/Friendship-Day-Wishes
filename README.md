# Ultra-Premium Friendship Day Website ❤️ — By ISHAAN 💙

A fully responsive, mobile-first, high-performance Friendship Day experience built with modern web technologies, cinematic animations, and a luxury Apple/Tesla landing page aesthetic.

## Features Included
- **Hero Section**: Large gradient greeting with exact signature `— By ISHAAN 💙` in a glowing cursive font.
- **Memory Vault**: Glassmorphism cards with humorous fallback messages and an interactive Swiper.js carousel.
- **Friendship Timeline**: Animated milestones tracking the journey from first conversation to forever.
- **Open Letter**: Interactive animated envelope that slides out an emotional Friendship Day letter.
- **Friendship Meter**: Animated progress bars for Trust, Fun, Support, Loyalty, and Drama.
- **Mini Game**: "Catch the Hearts" interactive arcade game with score tracking and confetti.
- **Surprise Button**: Explosive fireworks, confetti, and celebratory background transformations.
- **Cursor & Touch Effects**: Real-time heart and sparkle trails following mouse and touch movements.
- **Smooth Scrolling**: Powered by Lenis.
- **Theme Switcher**: Smooth Light/Dark mode toggling.
- **Audio Vibe**: Background music toggle with rotating visualizer indicator.

## Running Locally
Simply open `index.html` in any modern web browser or serve via a local static server (e.g., Live Server in VS Code). Vercel-ready for instant deployment.
